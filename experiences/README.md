# Global Agent Experiences

This directory contains sanitized, durable operating experience that can improve agents across repositories, devices, and sessions.

## Entry requirements

Each entry must provide:

- an observed basis;
- a generalized principle;
- explicit trigger conditions;
- a reproducible procedure;
- a verification method;
- scope limits and uncertainty;
- confirmation that publication was explicitly authorized.

Entries must remain suitable for a public repository. Project-local details, personal data, credentials, private paths, proprietary content, and one-off incidents stay outside this directory.
