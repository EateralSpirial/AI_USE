# Sync User Agent Context

## Purpose

Use AI_USE as portable upstream material and reconcile it into the current user's local global agent context.

The local context is the personalized working system. Preserve its valid user-specific experience while incorporating newer upstream principles, instructions, skills, and broadly reusable guidance.

## Read First

Read the repository `README.md`, `PRINCIPLES.md`, `AGENTS.md`, and both repository skills. Inspect the current agent platform's global instruction and skill conventions, then inspect the existing local context to the depth required for a sound merge.

## Method

1. Identify the current global context root, its entry instructions, skill library, and existing canonical owners.
2. Compare AI_USE and the local context by meaning as well as file content.
3. Install missing AI_USE skills and update existing ones to their current upstream meaning.
4. Reconcile the example `AGENTS.md` with the local global entry. Preserve durable local guidance, incorporate useful upstream changes, and consolidate semantic duplication.
5. Keep user-specific experience in its local owner. Keep project-specific truth inside its project.
6. Follow routes rather than copying complete definitions across several files.
7. Review the result as a capable agent entering the user's environment for the first time. Confirm that the entry is compact, each durable meaning has one owner, and relevant skills are discoverable.
8. Report the owners changed, any local guidance preserved, and any ambiguity that remains.

## Judgment

Choose the simplest structure that provides reliable onboarding. Existing local owners should evolve when they already express the required boundary. Create a new file or skill when the new meaning has a distinct reusable responsibility.

Use the tools available on the current device—Git, filesystem operations, platform installers, or direct editing—according to the environment. Keep the operation inspectable and verify the final local state.

This skill updates the local context. It performs no experience contribution to AI_USE.
